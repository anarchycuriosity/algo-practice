## 序列型动态规划
### 级数累积
```cpp
if (a[j] < a[i])
{
    dp[i] = max(dp[i], dp[j] + 1);
}
```
这个初看感觉很奇怪,虽然可以理解,但是第一次感觉很难想到

比如1 2 1 4,当j到第二个1的时候保持max,有种堆叠舍弃底层的感觉.因为这里需要找到前面序列中累计的级数的结果吗,max就是在找这个级数是多少

## 摆花
以后看到类似问题，不需要记“摆花模板”。

从头问：

① 我到底在一个个决定什么？

决定第i种花放多少盆

↓

② 做到一半以后，什么历史信息会影响未来？

只需要：

处理了多少种花
已经用了多少盆

所以：

dp[i][j]

↓

③ 我要算 dp[i][j]，最后一次决策有什么可能？

第i种花拿 k 盆


④ 如果最后拿 k 盆，之前必须是什么状态？
前i-1种花凑出 j-k

这就是从问题本身自然长出来的 DP，不需要背。

顺便说一句，你现在觉得“抉择突然复杂了”其实正好碰到了一个很重要的 DP 认知升级：DP 的转移并不要求每个状态只有两三个固定动作。 一个状态完全可以枚举几十、几百种“最后决策”。关键从来不是“有几个动作”，而是做出这个决策之后，剩余问题能否被某个已经定义好的状态完整描述。

这题里就是 k 可以有很多种，但选定 k 后，剩余问题立刻缩成 dp[i-1][j-k]。这一点抓住以后，这道题实际上比表面看起来规整得多。

## 状态压缩dp
### Q:我不太明白那两层for循环的设计,为什么外层是mask内层是第几头牛,虽然我大概明白这样才能覆盖集合,然后每头牛是mask的子集,但这和之前看到的01背包外层选方法内层列举价格有些不太一样
01 背包是在按“物品阶段”推进；状压 DP 是在按“集合状态”推进。
目前学到的01背包dp,区间dp,还有状压dp,问他们是如何推进的
01
dp[i-1][j]
       ↓
dp[i][j]

是按照选什么物品推进的,所以物品放第一层
区间dp是按照小长度到大长度,所以长度是依赖选项
状压dp是从当前有什么牛,然后选下一头牛,所以第二层选哪头牛,然后第一层是当前状体选了哪几头牛
