## 格子路径问题边界初始化为1有点匪夷所思
我们其实可以从状态转移方程来看
dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
比如顶上那行,它上面根本就没有格子,所以肯定是一路赋值过去
好吧其实你初始化起点即可

## 序列型动态规划
### 级数累积
```cpp
if (a[j] < a[i])
{
    dp[i] = max(dp[i], dp[j] + 1);
}
```
这个初看感觉很奇怪,虽然可以理解,但是第一次感觉很难想到

比如1 2 1 4,当j到第二个1的时候保持max,有种堆叠舍弃底层的感觉.因为这里需要找到前面序列中累计的级数的结果吗,max就是在找这个级数是多少
### 而且因为这个是序列型,所以两次for循环无法避免吗?
