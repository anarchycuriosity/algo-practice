### dp矩阵边界初始化
你以后写完 DP 的“核心递推”后，不要告诉自己：

“记得初始化边界。”

这个提醒太机械了，而且很容易忘。
应该问一个更第一性的检查问题：

我的递推能不能从初始状态，一路生成所有合法状态？
具体可以按这个顺序扫一遍。

假设你写：
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
马上问：
那么 i=0 和 j=0 谁来计算？
