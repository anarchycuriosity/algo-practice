### priority queue的比较器一定是传入一个叫做comp的类吗?名字一定要叫这么吗,然后里面有个什么operator(),我有点忘记这个语法了,是运算符重载吗,但是我没有看到重载的关键字啊.如果我想查源码应该怎么做,应该有类似python的__doc__这种东西吧?为什么sort的那个比较器只要传入一个bool函数即可,但是它们都叫比较器?
因为“比较器”不是一种具体语法类型，而是一个概念：

只要有一个东西，可以接收两个元素，并返回 bool，就可以充当比较器。
```cpp
struct Comp
{
    bool operator()(int a, int b) const
    {
        return a < b;
    }
};

sort(v.begin(), v.end(), Comp{});
```
